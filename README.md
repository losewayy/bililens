# BiliLens — B站视频 AI 智能精读与知识提取扩展

BiliLens 是一款面向哔哩哔哩（Bilibili）的现代化浏览器扩展，旨在将长视频内容高效转化为**带精准时间戳的结构化笔记与互动问答知识库**。

通过与各大兼容 OpenAI 协议的大语言模型以及内置的本地极速 ASR 推理引擎深度协同，帮助用户在数分钟内把握长视频核心脉络，支持音视频精准点播跳转、多轮深度探讨及一键沉淀至个人知识库。

---

## 核心特性

- **三层素材采集体系**：
  - **B站官方 AI 总结**：秒级拉取官方已有结构化提纲与摘要；
  - **高清字幕轨解析**：支持人工字幕与 AI 生成字幕的自动提取与清洗；
  - **本地极速 ASR 转写**：针对无字幕“生肉”视频，无缝联动内置的 Fun-ASR-Nano（0.8B）本地推理服务，亚秒级生成带时间戳与标点的逐字稿。
- **零额外凭证门槛**：依托 Chrome 扩展标准上下文机制发起同源请求，天然复用浏览器现有登录态，无需导出或手动填写 Cookie，无需复杂的签名逆向配置。
- **音视频双向交互**：生成的笔记章节与对话回答中均包含高亮时间戳，点击即可联动播放器平滑跳转至对应画面。
- **深度对话与思维链**：支持针对同一视频创建多个独立话题，完整支持思考过程（Reasoning Content）折叠展示及截图粘贴识别（Vision）。
- **本地知识库沉淀**：支持直接将结构化笔记（包含规范 YAML Frontmatter）写入本地 Obsidian 库，方便配合 Dataview 等插件进行聚合检索。
- **开箱即用的本地推理后端**：在 `server/` 目录下提供自包含的 Fun-ASR-Nano 极速服务，显存占用仅约 1GB，支持流式实时进度与 ETA 动态推流。

## 架构与工作机制

### 1. 素材优先级策略

```
                     ┌──────────────────────────────┐
                     │       打开 B站 视频页面        │
                     └──────────────┬───────────────┘
                                    │
                                    ▼
                     ┌──────────────────────────────┐
                     │ 检查是否有官方 AI 摘要/大纲?   │──[是]──► 获取结构化素材 (秒级)
                     └──────────────┬───────────────┘
                                   [否]
                                    ▼
                     ┌──────────────────────────────┐
                     │ 检查视频是否包含字幕轨?        │──[是]──► 获取字幕全文 (秒级)
                     └──────────────┬───────────────┘
                                   [否]
                                    ▼
                     ┌──────────────────────────────┐
                     │ 启用本地 ASR 推理服务 (18765) │──[是]──► 本地 GPU 极速转写
                     └──────────────────────────────┘
```

### 2. 上下文隔离与安全通信

扩展采用 Chrome Manifest V3 双世界隔离架构：
- **`MAIN World` 内容脚本**：运行于页面宿主环境，直接使用页面同源上下文获取数据，天然具备合法的同源认证环境；
- **`ISOLATED World` 内容脚本**：负责与扩展后台（Service Worker）及侧边栏进行安全消息中继；
- **侧边栏应用**：采用独立扩展宿主页面（Vue 3 构建），生命周期稳定，保障长文本流式总结过程平稳不中断。

## 快速上手

### 1. 构建扩展

确保本地已安装 [Node.js](https://nodejs.org/)（18+）与 [pnpm](https://pnpm.io/)：

```bash
# 安装依赖
pnpm install

# 编译扩展
pnpm build
```
编译产物将生成在 `.output/chrome-mv3` 目录下。

### 2. 加载至浏览器

1. 打开 Chrome / Edge 浏览器，访问 `chrome://extensions`；
2. 在右上角启用「开发者模式」；
3. 点击「加载已解压的扩展程序」，选中项目的 `.output/chrome-mv3` 目录；
4. 在扩展栏中将 BiliLens 固定至工具栏。

> 注：要求 Chrome 或 Edge 116 及以上版本（依托浏览器原生 Side Panel API）。

### 3. 配置大语言模型

点击插件图标 → 点击右上角 ⚙ 设置按钮，配置模型服务商与 API 信息：

| 配置项 | 说明 / 常见示例 |
| --- | --- |
| **API 地址** | 兼容 OpenAI `/chat/completions` 的端点（如 `https://api.siliconflow.cn/v1`、`https://api.deepseek.com/v1` 等） |
| **API 密钥** | 您在大模型平台申请的 API Key（如 `sk-...`） |
| **模型名称** | 所选服务商支持的模型标识（如 `deepseek-chat`、`Qwen/Qwen2.5-72B-Instruct` 等） |

- **自动拉取模型列表**：配置端点与密钥后，点击下拉框可直接自动获取该服务商支持的模型清单；
- **多配置管理**：支持保存多份模型配置方案（如主力云端模型、本地 Ollama 实例等），随时一键平滑切换。

## 本地 ASR 推理服务（可选）

当处理无任何官方或用户字幕的纯“生肉”视频时，可以启动项目附带的本地 ASR 服务实现语音转文字。

- **模型架构**：通义实验室 Fun-ASR-Nano（0.8B），自带 CTC 精确时间戳与标点符号恢复；
- **资源开销**：显存占用约 1GB，主流 RTX 30/40/50 系列显卡均可享受极速推理（RTF ~0.025）；
- **默认端口**：`18765`。

### 运行步骤：

```powershell
cd server

# 1. 首次使用：拉取定制模型权重 (~795MB 压缩包，自动高速拉取并解压)
python download_models.py

# 2. 启动服务 (Windows 用户可直接双击 start-server.bat)
.\start-server.ps1
```

服务在 `http://127.0.0.1:18765` 正常在线后，插件在解析生肉视频时将自动调度本地服务，并实时呈现分段转录进度与预计剩余时间。详细说明参见 [`server/README.md`](server/README.md)。

## 主要功能

### 1. 结构化精读笔记
- 打开视频点击「生成笔记」，大模型按章节梳理逻辑、提取关键知识点并生成 Markdown 笔记；
- 笔记中的时间戳可直接点击，无缝联动播放器定位；
- 支持一键导出并保存为 Markdown 文件或直接同步至 Obsidian 库。

### 2. 交互式视频问答
- 支持基于当前视频的全文内容进行自由提问，无需预先生成笔记；
- 支持创建多个平行对话话题，互不干扰；
- 针对模型返回的思考过程（Thinking / Reasoning）提供优雅的折叠展示；
- 支持通过剪贴板直接粘贴截图并向视觉大模型提问。

### 3. 字幕导出
- 当视频具有字幕轨时，视频卡片顶部提供专属导出入口，支持导出为 **SRT**、**VTT** 以及**纯文本**格式。

## 隐私与数据安全

- **数据仅本地流转**：所有 B站 请求均在用户本地浏览器发起，不经过任何中转服务器；
- **凭据安全**：大模型 API Key 仅保存在浏览器本地加密存储空间，绝不上传第三方；
- **按需调用**：仅在用户主动发起「生成笔记」或「发送提问」时，才向用户配置的模型端点发送对应视频字幕内容；
- **纯净无遥测**：不包含任何形式的用户行为统计、数据埋点或追踪代码。
