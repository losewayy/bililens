# BiliLens 视觉重构 · 设计规格

## 一、诊断：现有界面到底哪里不对

用户提供的两张截图暴露的问题，**不在 CSS，在结构**：

### 选项页
1. **服务商列表是「标签墙」**——8 个按钮，每个都是「圆角框 + 灰字」，
   视觉重量完全相同，扫视时无法区分。而实际上它们差异很大
   （国产/海外、云端/本地、官方/中转）。
2. **单列大卡片自上而下堆叠**，所有字段等宽等高，
   眼睛没有落点，滚动像在填表。
3. **状态反馈彼此孤立**：`域名已授权` 是一条绿框，`测试连接` 是另一条按钮，
   它们其实描述同一件事（能否连通），却被拆成两个不相干的行。
4. **最大问题：读完记不住任何东西。** 页面没有主张，只是把字段摆出来。

### 侧边栏
1. **时间戳是一堆粉色小胶囊**，与正文抢视觉；
   而右侧导航又是一列灰字——同一份时间信息出现了两次，彼此不呼应。
2. **笔记正文与视频之间没有视觉联系**。点击时间戳能跳转，
   但界面上完全看不出"这条笔记属于视频的第 2 分 30 秒"。
3. 顶部信息、模式条、正文、底部操作四段式，**每一段都是横条**，
   缺少一个能统摄全篇的结构。

## 二、核心主张

> **把「时间」做成界面上唯一的视觉主角。**

依据：BiliLens 的全部价值 = 把线性的视频时间压成可扫读的文字。
它的核心数据是时间戳，核心动作是「跳回某一刻」。
因此界面里该被强化的不是卡片、图标或渐变，**是时间轴本身**。

## 三、色板（6 色，全部从 bilibili 品牌色推导）

| 名称 | 值 | 用途 |
|---|---|---|
| `--ink` | `#0d0e12` | 深色模式底色（近黑，微冷） |
| `--paper` | `#fbfbfd` | 浅色模式底色（冷白，非奶白） |
| `--bili` | `#fb7299` | bilibili 品牌粉 —— **只用于时间与当前状态** |
| `--bili-deep` | `#e0507a` | 粉色按下态 / 深色模式下的粉色 |
| `--mist` | `#8b93a4` | 次级文字（带蓝调的中灰，非纯灰） |
| `--line` | `#e6e8ee` | 分隔线 |

**克制原则**：粉色是稀缺资源。整个界面里，粉色**只出现在与"时间"和"当前"有关的地方**
（时间刻度、进行中状态、选中项）。这样用户一眼扫过去，粉色所在即是重点。

## 四、字体

| 角色 | 字体栈 | 理由 |
|---|---|---|
| 正文 | `system-ui` / `PingFang SC` / `Microsoft YaHei` | 界面文字，追求无个性、高可读 |
| **时间数字** | `ui-monospace` + `tabular-nums` | **等宽 + 表格数字**，让 0:01 与 11:26 占据完全相同的宽度，成列时形成真正的「刻度尺」而非参差文本 |

时间用等宽表格数字是这个设计的**技术支点**：没有它，时间轴就是歪的。

## 五、签名元素（Signature）

### 时间轴导轨（Time Rail）

侧边栏笔记左侧一条**贯穿全篇的竖线**，每个章节标题处有一个**刻度节点**：

```
      ┌─ 2px 竖线，贯穿整个笔记
      │
  ●───┼── 3:15  一对一、聚合来源与工程化信任
  │   │          · 反刍意见：只有一个老师会只剩单一视角
  │   │          · 回应：把来源和界面混为一谈……
      │
  ○───┼── 4:22  系统两大核心原则
      │
```

- 实心节点 = 当前阅读位置；空心节点 = 其他章节（随滚动实时切换）
- 点击节点或时间 → 视频跳转
- 刻度线本身就是滚动进度的隐喻，**同时替代了原来那列独立的右侧导航**

这个元素无法被套用到任何别的产品上：它是"视频笔记"独有的结构。

### 选项页的对应物：分组而非平铺

服务商不是"按钮列表"，而是**按真实差异分组的身份卡**：

```
  云端 API                              本地/自建
  ┌────────────┐ ┌────────────┐         ┌────────────┐
  │ ◈ DeepSeek │ │ ◈ 硅基流动  │   ...   │ ◈ Ollama   │
  │ 官方直连    │ │ 国内聚合    │         │ 完全离线    │
  └────────────┘ └────────────┘         └────────────┘
```

每张卡带**真实 logo**（已用 `scripts/fetch-logos.mjs` 抓取 8 家官方标识）
+ 一句"它是谁"的定位说明。分组标题编码了真实信息（部署方式），不是装饰。

## 六、结构重排

### 选项页
从「单列大卡片」改为**左侧固定导航 + 右侧内容分区**：
- 左栏：大模型 / 笔记行为 / 保存位置（三项 + 当前状态摘要）
- 右栏：对应分区内容，带**序号与说明**
- 顶部：一句价值主张 + **当前配置的实时摘要**（让用户一眼知道"我现在用的是谁"）

连接状态与测试按钮**合并为一个连通性区块**，不再各行其是。

### 侧边栏
- 顶部：视频信息压缩为**两行**（标题 + 元信息行），封面缩为 44px 方图
- 素材状态徽章改为**行内小字**，不再抢占视觉
- 模式选择改为**分段控件**，与「开始」按钮同处一行
- 正文：时间轴导轨（见上）
- 底部操作栏**只保留一个主按钮**，其余收进「⋯」

## 七、刻意不做的事（克制）

- ❌ 不加渐变背景
- ❌ 不给每个标题配 emoji 图标（原实现用了 📌🧭🎯，属于装饰性图标泛滥）
- ❌ 不加左侧彩色 border accent 的卡片
- ❌ 不加无意义的统计数字（"已生成 128 条笔记"之类）
- ❌ 不用动画堆砌；只保留两处有意义的动效：
  流式生成时的光标脉冲、章节切换时节点的高亮过渡

## 八、动效（克制，两处）

1. **生成中**：末尾一个脉冲光标，表明"还在写"
2. **刻度节点**：滚动切换时 width 与颜色过渡 160ms

均遵守 `prefers-reduced-motion`。
